# Project Rules & Learned Guardrails

## 1. Arabic Intent & Terminology Disambiguation
- **تفسير الأفعال والمصطلحات العربيّة**: عند قراءة عبارات مثل "وارسل ايه بي اي" أو "وارسل API"، يجب التمييز دائماً بين فعل **"وأَرْسِل API"** (بمعنى إرجاع/إرسال استجابة API نظيفة للفرونت إند) وبين أسماء الشركات/الخدمات الخارجية، والتأكد من القصد قبل افتراض وجود خدمة أو شركة خارجية مجهولة.

## 2. OAuth Callback & FRONTEND_URL Alignment
- **مطابقة منفذ الفرونت إند في البيئة المحلية**: عند إعداد أو تصحيح مسارات إعادة التوجيه لـ OAuth (سلة / زد)، يجب دائماً التأكد من أن متغير `FRONTEND_URL` في ملف `.env` يطابق بالضبط المنفذ والرابط الذي يعمل عليه سيرفر الفرونت إند الحالي لتفادي خطأ `ERR_CONNECTION_REFUSED`.

## 3. Global API Route Alignment (No `v1` Prefix)
- **إزالة البادئة `v1` كلياً من مسارات الـ API**: يجب تسجيل كافة مسارات الـ API في `routes/api.php` مباشرة بدون البادئة `v1` (مثل `/api/proxy/*`, `/api/auth/*`, `/api/me`, `/api/store/profile`, `/api/user/profile`) لتتطابق 100% مع نداءات الفرونت إند الحالية وتفادي أخطاء 404.

## 4. Streamlined Proxy Forwarding Over In-Memory Manipulation
- **عدم الفلترة المكررة بالذاكرة**: يُكتفى بترجمة أسماء معاملات البحث والباجينيشن وإرسالها للمنصة الخارجية مباشرة دون إجراء عمليات تقطيع أو فلترة مكررة بحلقات تكرارية بالذاكرة المحلية بالسيرفر.
